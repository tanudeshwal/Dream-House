# Dream House – Budget-Friendly House Planner

## Version 2

This version includes:
- Plot length and width input
- Budget estimation
- Family/room requirements
- Material and accessory suggestions
- House plan gallery
- Three sample floor-plan images
- Automatic sample-plan selection in the generated result
- Responsive Bootstrap design

## Run
Open `index.html` in a browser.

For the best experience, keep the project folder structure unchanged.

## Important
The cost calculations and floor plans are educational/project estimates only. Final architectural, structural, quantity and approval decisions should be made by qualified professionals according to local rules.


## Budget-based house maps
- Below ₹7,00,000 → House Plan 1
- ₹7,00,000 to below ₹10,00,000 → House Plan 2
- ₹10,00,000 and above → House Plan 3

The three user-provided sample maps are used as the plan images.
